# スマートディスプレイmini

横向き全画面の Android スマートディスプレイ。常時表示のデジタル時計を中心に、時報・他アプリの通知・メディア操作・SwitchBot の機器操作だけに絞った小さな構成。ランチャー名は「スマートディスプレイmini」、アイコンは時計の右上に「M」を重ねている。インストール ID は `app.smartdisplay.mini` で、本体（`app.smartdisplay`）とは別アプリとして共存できる。

Android Studio でこのフォルダを開く。SwitchBot を使うときは `local.properties` に `switchbot.token` と `switchbot.secret` を書く。

## 機能概要

### 時計画面

- 日付・時刻の常時表示（画面消灯防止）
- 日付の下に、祝日と季節の行事を出す。重なる日は祝日を先にして「、」でつなぐ。節分、彼岸、八十八夜、母の日、父の日、入梅、半夏生、夏至、土用の丑の日、冬至、十五夜、イースターはその年の日付で出す。彼岸は春分・秋分の前後3日、お盆は8月13日から16日
- 日の出・日の入りの90分前になると、その時刻をアイコン付きで出す（小平市の位置から端末内で計算。通信しない）
- 再生中のメディアがあれば、画面下にタイトル・アートワーク・再生位置を出す。タップするとメディア画面へ進む
- タップでメニューを開く
- 通知バナー表示中は時計領域が縮み、バナーと並ぶ
- インターネットに繋がらないときは、バナーと音声で「接続エラー」を知らせる
- 充電が始まると画面下中央に「充電を開始します。」、電源供給がなくなると「充電を終了します。」と出す。音は鳴らさない
- Bluetooth機器の接続時は「Bluetooth機器「機器名」に接続しました。」、切断時は「Bluetooth機器「機器名」を切断しました。」と、同じ位置に出す。Wi-Fiは「Wi-Fi「アクセスポイント名」に接続しました。」と「Wi-Fi「アクセスポイント名」を切断しました。」。音は鳴らさない。起動時にすでに繋がっているものは出さない。Wi-Fiの名前には位置情報の許可が要る。端末の位置情報もオンにする。名前が取れないときは「不明」にする

### 時報

- 通常テーマのメロディ（0・15・30・45分）と時刻読み上げ
- 読み上げ中の半角スペースは「、」にして一呼吸置く。英語の文の中と、単体の英語のあとはそのまま。日本語にくっついた英語のあとに日本語が続くときは「、」にする。他アプリの通知も同じ
- 特殊時刻のイントロ音（0時、3時、8時、10時、12時、12時30分、13時30分、18時）
- 3の倍数時（0時、3時、6時、9時、12時、15時、18時、21時）は、日付と曜日のあとに祝日と季節の行事を読んでから時刻を読む。重なる日は祝日を先にして「、」でつなぐ
- ON/OFF の設定

### 通知

- 他アプリの通知をバナーで表示し、音声で読み上げる。読み上げのオンオフと、音の出ない通知も読むかを「通知設定」で決める
- 半角スペースは「、」にして一呼吸置く。英語の文の中と、単体の英語のあとはそのまま。日本語にくっついた英語のあとに日本語が続くときは「、」にする。再生コントロールと、Chromeの「サイトで〜が使用されています」「共有されています」、Spotifyの「Spotifyの接続」、Boseの「同期を維持します。」は読まない。音の出ない通知を読むときは共通の通知音を鳴らし、音の出る通知の音は端末に任せる
- 通知アクセスの許可は初回起動の案内で出す
- アプリの音（時報・通知の読み上げとSE・タップ・サウンドテスト。時報テストは除く）は、Wi-Fi接続中、他アプリのメディア再生中、Bluetoothのイヤホン／ヘッドホン／スピーカー接続中だけ鳴らす。それ以外では出さないが、バナー表示はそのまま。通知設定の「外出中も鳴らす」を一時的にオンにすると鳴らせる。Wi-Fi・メディア・Bluetooth接続が次に満たされたとき、またはアプリ終了でオフに戻る

### メディア

- 端末のメディアセッション（通知に出ている再生）を一覧し、再生・一時停止・前後の曲・シャッフル・リピートを操作する
- Spotify など、通知に再生コントロールが出るアプリは同じように操作できる

### 機器操作

- SwitchBot の温湿度（リビング／寝室／浴室／外）
- 画面を開いたときと、更新ボタンで取得
- カテゴリ、機器の順に選び、操作ボタンで実行
- メニューの音量パネルの右「クイック操作」から、テレビ・セレクタ・扇風機、ライト、カーテン、玄関ドアのよく使う操作をまとめて実行
- 操作の通信中は他の操作を受け付けない

### 行事

- メニューの「行事」で、祝日と季節の行事を近い順に見る。振替休日は出さない
- 「祝日」で祝日だけに絞り込める。「すべて」で戻す
- 各行は名前、次の日付、あとx日。祝日は名前のあとに「祝日」と出す。当日は「今日」。月日は2桁で、来年以降は年を付ける。日数は桁区切り
- 同じ日が重なるときは祝日を先にする。期間の行事は、今日以降で最初の日を次の日付にする

### カレンダー

- 端末カレンダーの予定を「今日このあと」「明日」「一週間以内」で見る（表示のみ。読み上げや通知はしない）
- カレンダーの許可は初回起動の案内で出す。許可がなければ、メニューを開いたときにも確認する

### その他（設定）

- メディア音量
- 時報の ON/OFF
- 通知設定（読み上げ、サイレント通知の読み上げ、外出中も鳴らす）
- テスト実行（時報テスト。ランダム再生、0・15・30・45分、特殊時刻）
- サウンドテスト
- 通信ログ（直近3時間の外部通信。SwitchBot）
