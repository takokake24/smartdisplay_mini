# smartdisplay

横向き全画面の Android スマートディスプレイ。常時表示のデジタル時計を中心に、時報・通知・天気・交通などをまとめて扱う。

Android Studio でこのフォルダを開く。

## 機能概要

### 時計画面

- 日付・時刻の常時表示（画面消灯防止）
- 日付の下に、祝日と季節の行事を出す。重なる日は祝日を先にして「、」でつなぐ。節分、彼岸、八十八夜、母の日、父の日、入梅、半夏生、夏至、土用の丑の日、冬至、十五夜、イースターはその年の日付で出す。彼岸は春分・秋分の前後3日、お盆は8月13日から16日
- タップでメニューを開く
- 通知バナー表示中は時計領域が縮み、バナーと並ぶ
- 充電が始まると画面下中央に「充電を開始します。」、電源供給がなくなると「充電を終了します。」と出す。音は鳴らさない
- Bluetooth機器の接続時は「Bluetooth機器「機器名」に接続しました。」、切断時は「Bluetooth機器「機器名」を切断しました。」と、同じ位置に出す。Wi-Fiは「Wi-Fi「アクセスポイント名」に接続しました。」と「Wi-Fi「アクセスポイント名」を切断しました。」。音は鳴らさない。起動時にすでに繋がっているものは出さない。名前が取れないときは「不明」にする

### クロック

- メニューの「クロック」からタイマーとアラームを使う
- タイマーは時・分・秒を指定して開始する。作動中は時計画面の日付の下に残り時間を出す
- アラームは時刻を指定する。設定中は同じ位置に「アラーム」と設定時刻を出す
- 両方あるときは、タイマー、アラームの順で同じ行に出す
- 時間になると通知で知らせ、タイマーは「タイマーが終了しました。」、アラームは「アラームが作動しました。時刻は、7時30分です。」と読んでから、外出アラートの曲をシャッフルして流す。通知音は鳴らさない。曲が終わると次の曲に進む
- 自分で止めるか、鳴ってから5分で止まる。自動で止めたときは「タイマーが停止しました。」または「アラームが停止しました。」を通知一覧に追加する。画面には出さず、読み上げない
- 片方が鳴っているあいだにもう片方が鳴ると、先のほうを自動停止して、あとから鳴ったほうに切り替える

### 時報

- 季節テーマ（通常／土日／祝日／クリスマス）のメロディと時刻読み上げ
- 読み上げ中の半角スペースは「、」にして一呼吸置く。英語の文の中はそのまま。英語のあとにスペースを挟んで日本語が続くときは「、」にする。時報のあとに続ける案内、予定の15分前、他アプリの通知も同じ
- 特殊時刻のイントロ音
- 時報後に天気・予定の案内を続けて流せる（正午と 23:30）
- 3の倍数時（0時、3時、6時、9時、12時、15時、18時、21時）は、日付と曜日のあとに祝日と季節の行事を読んでから時刻を読む。重なる日は祝日を先にして「、」でつなぐ。0時と正午はそのあと今日の記念日を案内する。正午は天気と予定のあと、今日の格言を1件読む
- ON/OFF と当日テーマの上書き設定

### 日の入り

- 日の入りの時刻に通知する。カーテンが開いていれば、閉まる注意を読む
- 続けて、このあとの天気と予定を読む
- 時報と重なったら、時報のあとに回す

### 朝のまとめ

- 6時・7時・8時・8時30分・9時に、今日の天気・予定・運行・ごみ出しを読み上げ、続けて期限が近い食品があれば案内する。天気の案内ではリビングと外の温湿度も読む
- 時報前のイントロは8時だけ。時報と重なったら時報のあとに続く。時報を切っていても出る
- 運行は異常がある路線だけ読み、平常なら JR中央快速線と東京メトロ丸ノ内線が平常運転だと伝える

### 通知

- バナー表示と音声読み上げ。他アプリの通知は、読み上げのオンオフと、音の出ない通知も読むかを設定できる。半角スペースは「、」にして一呼吸置く。英語の文の中はそのまま。英語のあとにスペースを挟んで日本語が続くときは「、」にする。再生コントロールと、Chromeの「サイトで〜が使用されています」「共有されています」は読まない。音の出ない通知を読むときは共通の通知音を鳴らし、音の出る通知の音は端末に任せる
- 履歴の確認
- カテゴリ単位の「今日は通知しない」
- 緊急案内時は音量を一時的に上げる設定あり

### メディア

- Spotify に接続し、再生先（この端末、ホームグループ、Nest Hub、Nest Hub 2、Nest Mini）とプレイリスト（A面、B面、その他）を選んで再生する
- 通知に出ている他の再生も、同じ画面から操作できる

### 機器操作

- SwitchBot の温湿度（リビング／寝室／浴室／外）
- 画面を開いたときと、更新ボタンで取得
- カテゴリ、機器の順に選び、操作ボタンで実行
- メニューの音量パネルの右「クイック操作」から、テレビ・セレクタ・扇風機、ライト、カーテン、玄関ドアのよく使う操作をまとめて実行
- 操作の通信中は他の操作を受け付けない

### 天気予報（小平市）

- 今日／このあと／明日などの予報表示
- 時報に合わせた天気案内
- 6時・7時・8時・8時30分・9時・12時・23時30分・日の入りの案内の最後に、リビング温度計と外温湿度計の温湿度を読む。取れないときはその旨を表示し、読み上げる
- 直近の天候悪化などの検知通知

### 気象警報（小平市）

- 警報・注意報の表示
- 特別警報／危険な警報は全画面案内

### 地震

- 緊急地震速報の全画面案内と音声
- 震度情報の通知

### 行事

- メニューの「カレンダー」の次「行事」で、祝日と季節の行事を近い順に見る。振替休日は出さない
- 「祝日」で祝日だけに絞り込める。「すべて」で戻す
- 各行は名前、次の日付、あとx日。祝日は名前のあとに「祝日」と出す。当日は「今日」。月日は2桁で、来年以降は年を付ける。日数は桁区切り
- 同じ日が重なるときは祝日を先にする。期間の行事は、今日以降で最初の日を次の日付にする

### カレンダー

- 端末カレンダーの予定表示
- 時報に合わせた今日／このあと／明日の予定案内
- 開始の15分前に通知し、「〜まで、あと15分です。」と読む。予定名の半角スペースは「、」にして一呼吸置く。英語の文の中はそのまま。英語のあとにスペースを挟んで日本語が続くときは「、」にする。終日は出さない。起動が遅れたときは残りの分を切り上げる
- 「今日は通知しない」は、この直前通知だけ止める

### 歩数計

- ヘルスコネクトの歩数を、月曜始まりの週で見る
- 23:30 の時報のあと、明日の天気の前に今日と今週の歩数を読む

### アラート

- キッチンライトが薄い黄色・明るさ 15% のとき、外出モードのアラートを全画面で出す
- 4桁の暗証番号で解除する。3回間違えると 2 分間入力できない
- 発動中は曲を流し、インカメラで撮影する。履歴から時刻と写真を見られる
- メニューの「アラート」を開くにも暗証番号が要る

### 運行情報

- JR中央快速線・東京メトロ丸ノ内線の運行状況
- 遅延・運休などの変化を通知

### 鉄道時刻表

選んだ駅を発車する列車を表示する。駅は国分寺・三鷹・吉祥寺・荻窪・中野坂上・西新宿・新宿・東京・西国分寺・立川。

- 方面チップは路線名と方面。1方向だけの路線は路線名だけ。左のメニューからも路線を選べる。見出しの直通先はナンバリングで示す
- 種別・行き先・当駅始発で絞り込み
- 他路線への直通を行き先の下に出す。停車駅では、途中で変わる種別も出す
- 列車をタップすると停車駅と発着時刻を表示

### バス時刻表

近隣の方面・発着をまとめて表示する。

- 方面タブ: 国分寺・武蔵小金井方面／花小金井・昭和病院方面／一橋学園・小平方面／国分寺駅発／武蔵小金井駅発／中央道府中発
- 経由地での絞り込み
- 便をタップすると停車停留所と発着時刻を表示
- 停車停留所のベルで乗車通知（発車 15・10・5・3 分前）
- 複数バス会社のダイヤを統合（取得失敗した会社は凡例で赤字）

### 記念日

- 日本記念日協会の認定記念日を、0時と正午の時報で案内する
- 通知の見出しは「今日の記念日」。入りきらない分は「他x件」
- 読み上げは並びの先頭10件。「今日は、〜です。」10件を超えるときは「そのほかに、x個の記念日が登録されています。」と続ける
- 前日にもあった記念日は案内の並びを後ろへ下げ、その日だけのものを先に読む
- 祝日や、日付の下に出す行事と同じ名前の記念日は案内しない
- メニューの「記念日」で、日付を変えて認定記念日を確認できる。タップすると由来を出す
- 期間の注記（「１１月１日から１１月７日まで」「／５月分」など）は一覧と読み上げには出さず、由来の中だけに出す

### 格言

- 正午の案内の最後に、名言を1件ランダムに読む
- 通知の見出しは「今日の格言」。本文の下に作者を右揃えで出す
- 読み上げは「「本文」。作者の格言です。」

### ごみ出し

- 23:30 の明日の予定のあと、「明日のごみ収集は、〜です」と読む
- 朝のまとめでは「今日のごみ収集は、〜です」と読む
- メニューの「ごみの日」で、種類ごとの次の収集日と残り日数を、近い順に見る
- 収集日の 9:00 未満は「今日」、9:00 以降は次の収集日
- 毎年 12/30〜1/3 は収集しない

### 賞味期限

- メニューの「行事」の次「賞味期限管理」で、期限の早い順に商品を見る
- 商品名と日付は通常の色。残り日数は右の色付き枠で、数字を大きく出す。過ぎたものは赤、今日から7日以内はオレンジ
- 朝のまとめは今日のごみのあと、昼のまとめはこのあとの予定のあと、夜の通知は明日のごみのあとに、期限が近いものがあれば案内する
- 通知の見出しは「賞味期限管理」。導入は「以下の賞味期限が近づいています。」で、商品名は通常の色、残日数は色付きの枠
- 読み上げは「賞味期限が近いものがあります。」から始め、商品名と個数のあとに間を置いて「商品名、x個が、あとx日。」「商品名、x個が、今日まで。」。最後の文だけ「です。」で終える
- 近いものがなければ案内しない

### ナイトモード

- 0:00〜6:00 は明るさの自動を切り、設定した割合に固定する（最低 1%、初期 15%）
- 時報の音量はナイトモードの設定で下げる（初期 40%）。メロディと「x時です」の読み上げに使い、スライダーと「試す」でその大きさの時報を短く試聴できる。通知の読み上げは通常の音量、緊急通知は緊急警報音量のまま
- 明るさのスライダーを動かしているあいだはその明るさになり、離して 1 秒後に元の明るさへ戻る
- 通知が出ているあいだは、切り替える前の明るさに戻す。消えるとナイトモードの明るさに戻す
- 緊急の全画面案内は、ナイトモードに関係なく最大の明るさにする。半分の通知になると通常の明るさ、それが消えてナイトモード中ならナイトモードの明るさに戻す
- 6:00 を過ぎるかオフにすると、元の自動設定と明るさに戻す
- メニュー表示中、最後の操作から 60 秒は、切り替える前の明るさに戻す

### その他（設定）

- メディア音量
- 時報・カレンダーの設定
- 音量・明るさ（ナイトモード、緊急警報音量、外出アラート音量）
- 各種テスト実行
- サウンドテスト
- 通信ログ（直近の外部通信）
